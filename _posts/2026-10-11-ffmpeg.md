## 1. 查看帮助文档

| 命令                  | 功能        |
| ------------------- | --------- |
| `ffmpeg -h`         | 查看基础帮助    |
| `ffmpeg -h long`    | 查看高级选项    |
| `ffmpeg -h full`    | 查看全部选项    |
| `man ffmpeg`        | 查看系统手册    |
| `ffmpeg -version`   | 查看版本和编译信息 |
| `ffmpeg -buildconf` | 查看编译配置    |

推荐使用：

```
ffmpeg -h full | less
```

这样可以分页浏览完整帮助文档，使用方向键滚动，按 `/` 搜索，按 `q` 退出。

## 2. FFmpeg 中文常用命令参考

### 基础命令结构

```
ffmpeg [全局选项] -i 输入文件 [输出选项] 输出文件
```

例如：

```
ffmpeg -i input.mp4 output.mp3
```

读取 `input.mp4`，提取并转换其音频，生成 `output.mp3`。

### 常用参数

| 参数        | 中文含义        |
| --------- | ----------- |
| `-i`      | 指定输入文件      |
| `-y`      | 自动覆盖已有输出文件  |
| `-n`      | 禁止覆盖已有文件    |
| `-ss`     | 指定起始时间      |
| `-t`      | 指定处理时长      |
| `-to`     | 指定结束时间      |
| `-c:v`    | 指定视频编码器     |
| `-c:a`    | 指定音频编码器     |
| `-c copy` | 直接复制流，不重新编码 |
| `-b:v`    | 设置视频比特率     |
| `-b:a`    | 设置音频比特率     |
| `-r`      | 设置视频帧率      |
| `-s`      | 设置视频分辨率     |
| `-vn`     | 不输出视频       |
| `-an`     | 不输出音频       |
| `-vf`     | 设置视频滤镜      |
| `-af`     | 设置音频滤镜      |

注意，部分参数的位置会影响其作用，例如 `-ss` 放在输入文件之前或之后，行为可能有所区别。

## 3. 查询 FFmpeg 支持的功能

| 命令                  | 中文含义       |
| ------------------- | ---------- |
| `ffmpeg -formats`   | 查看支持的封装格式  |
| `ffmpeg -codecs`    | 查看支持的编解码格式 |
| `ffmpeg -encoders`  | 查看可用编码器    |
| `ffmpeg -decoders`  | 查看可用解码器    |
| `ffmpeg -filters`   | 查看支持的滤镜    |
| `ffmpeg -protocols` | 查看支持的协议    |
| `ffmpeg -hwaccels`  | 查看可用硬件加速方法 |

还可以查看某个具体组件的帮助，例如：

```
# 查看 H.264 编码器的参数
ffmpeg -h encoder=libx264

# 查看视频缩放滤镜的参数
ffmpeg -h filter=scale

# 查看 AAC 编码器的参数
ffmpeg -h encoder=aac
```

## 4. 常用命令示例

视频转换：

```
ffmpeg -i input.mov output.mp4
```

无损提取原始音频流（不重新编码）：

```
ffmpeg -i input.mp4 -vn -c:a copy output.m4a
```

此命令适用于输入音频流与 M4A 容器兼容的情况，例如 AAC 音频。

转换为 MP3：

```
ffmpeg -i input.wav -c:a libmp3lame -b:a 192k output.mp3
```

截取 30 秒音频：

```
ffmpeg -ss 00:01:00 -i input.mp3 -t 30 output.mp3
```

压缩视频：

```
ffmpeg -i input.mp4 -c:v libx264 -crf 23 -preset medium output.mp4
```
